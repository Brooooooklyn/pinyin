# Benchmark evidence

The [consolidated research report](../../docs/performance-research.md) explains the algorithms, implementation, measurement methods, limitations, and source references. This directory retains raw samples and provenance; each stage has its own baseline.

| Stage                     | Evidence                                                                                                                                                 | Role                                                                                                                  |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Final SIMD implementation | [remaining-simd/](remaining-simd/)                                                                                                                       | Complete native/WASI calls, pinyin-pro comparisons, independent Jieba parity, controls, source hashes, and validation |
| UTF-16 integration        | [encoding/](encoding/)                                                                                                                                   | Complete-call input/output encoding improvements, startup, memory, and binary size                                    |
| JSON escaping prototype   | [json-escape/](json-escape/)                                                                                                                             | Five-mode same-binary experiment that selected the final UTF-8 writer                                                 |
| SIMD candidate research   | [simd-research/](simd-research/)                                                                                                                         | Isolated kernels, same-binary output experiments, input-copy controls, and trie analysis                              |
| UTF-8 validation          | [simdutf8/](simdutf8/)                                                                                                                                   | Validators, controlled Rust conversion, complete byte-input calls, and unchanged-string controls                      |
| Jieba integration         | [jieba/](jieba/)                                                                                                                                         | Phrase/Jieba comparisons, cold initialization, large-text memory, and rejected strict boundaries                      |
| Initial static core       | [arrays.json](arrays.json), [strings.json](strings.json), [heteronyms.json](heteronyms.json), [runtime.json](runtime.json), [scaling.json](scaling.json) | Original release binding versus the first standalone core                                                             |

Results retain options, output-equivalence flags, input/output hashes, timing samples, and runtime/build identities. Different stages must not be pooled or ranked as if collected in one experiment. Natural-text comparisons with different readings measure runtime, not equivalent pronunciation accuracy. Small changes on the active desktop can reflect noise; the final report includes follow-up controls.

The original baseline is release commit `f4409a36802672f6677a8033d63109b16a8a2f40`. Rebuild it in a separate checkout. Reconstruct the two intermediate native baselines with `python3 benchmark/build-baseline.py encoding` or `python3 benchmark/build-baseline.py remaining-simd`. Each applies the corresponding `source-before.patch` in an isolated directory, verifies `source-before.json` hashes, builds with the recorded Cargo lockfile, and removes temporary sources on exit. The rebuilt addon is `target/<stage>-baseline/before.node`. The older `encoding/before.patch` remains as original experiment provenance; use the new builder for the final tree.

Absolute temporary paths and artifact hashes in the original JSON files describe the measured run. Those files are historical records; paths need not still exist. Native binaries, temporary checkouts, build caches, and disassembly dumps are not checked in. Rebuilt binary hashes can differ with compiler, linker, or temporary path changes, even when verified source files match.

The report's marked tables are generated by `scripts/summarize-benchmarks.py`, `scripts/summarize-jieba-benchmarks.py`, `scripts/summarize-utf8-benchmarks.py`, `benchmark/simd-research/analyze.py`, and `benchmark/remaining-simd/summarize.py`. `benchmark/analyze-encoding.py` emits the encoding CSV. The final implementation's validation record predates documentation consolidation; see PR checks for subsequent CI status.
